# 6.1800 Tidbits

Welcome to the 6.1800 tidbits website repository! This site contains a curated collection of interesting resources, articles, videos, and experiments related to computer systems topics covered in MIT's 6.1800 course (Spring 2025).

## What is this?

This is a supplementary learning resource that provides additional content for topics we don't have time to fully explore in class. The website features links and resources organized by topic, including:

- **DNS** - Interactive tools and podcasts about domain name systems
- **Unix** - Historical content and modern perspectives on Unix systems
- **Networking concepts** - Encapsulation, overlay networks, end-to-end argument
- **Distributed systems** - CDNs, file systems (GFS, ZFS), physical infrastructure
- **Security** - Vulnerabilities, DNSSEC, and cryptographic implementations

## Viewing the site

The site is a simple static HTML page. To view it locally:

1. Clone this repository
2. Open `index.html` in your web browser

Or visit the live site at: [https://liliwilson.github.io/tidbits/](https://liliwilson.github.io/tidbits/)
